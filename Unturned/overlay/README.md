# Overlay VOX

Ce dossier contient uniquement les nouveaux fichiers à copier dans la racine du SDK Unturned.

Exemple futur : `overlay/Assets/VOXGraphics/...` sera copié vers `SDK/Assets/VOXGraphics/...` par `bootstrap.ps1`.

Ne pas y recopier les fichiers officiels modifiés : ceux-ci doivent être représentés par des patches dans `../patches/` afin de garder les différences avec l'amont lisibles et reproductibles.
