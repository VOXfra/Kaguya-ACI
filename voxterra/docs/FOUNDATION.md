# VoxTerra Foundation

This directory is the maintainable Fabric source tree for VoxTerra.

Foundation owns the experience-defining glue and custom gameplay only. Heavy rendering/world systems such as Sodium, Iris, Voxy, Lithosphere and Serene Seasons remain external dependencies.

## Locked direction
- Minecraft Java 26.2 / Fabric / Java 25
- Foundation first: custom HUD/crosshair and integration layer
- First playable age: Stone & Fire
- No artificial inventory weight/encumbrance system
- No copying from restrictive third-party mods
- External systems are integrated through APIs/compatibility where appropriate
